# Requirements traceability

This audit maps each requirement in the plan to the code that implements it and the test that proves it. It was written on 3 October 2026 from the working tree. I read each cited file and found each test name with `grep`. The rows closed on 3 October 2026 were checked by a full run that day. It covered lint, typecheck, unit tests, build, preflight and Playwright. That run is in `.yolo-sisyphus/handoff/verify-gaps.md`. The staff access code and the shared rate-limit store were checked the same day in `.yolo-sisyphus/handoff/verify-hardening.md`. Other runtime results come from the reports in `.yolo-sisyphus/handoff`. Section 11 was added on 3 October 2026 from `authz-fuzz.md` and `fault-injection.md`, and each of its tests passed in a verbose run of `apps/api/test/security` and `apps/api/test/recovery` that day. Route matrix and fuzz test names are generated, so they appear in that run's output, not as literals. Names built by `it.each` or a loop, such as the recovery `%s` cases, are cited as they print. On 3 October 2026 every cited path was checked with `ls` and every cited line number was read again and corrected.

Of the 123 rows, 117 are Present and 6 are Partial. None is Missing, and none is an Owner decision.

Status is one of Present, Partial, Missing, Owner decision, or In progress. Paths are relative to the repo root. A proof in the form `file` `name` is a test in that file with that exact name.
